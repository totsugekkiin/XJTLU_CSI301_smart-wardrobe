# Smart Wardrobe 智能衣橱

Smart Wardrobe 是一款原生 Android 智能衣橱，目前版本为 0.6.14。它支持衣物建档、洗护记录、穿搭画布和穿着日历。照片保存在应用私有目录，其余记录保存在本机 SQLite。淘宝网页和商品图片导入需要联网。

0.6.5 在「衣橱 → 添加 → 从淘宝导入」支持粘贴淘宝分享文案、商品链接或阿里 CDN 商品图地址。若网页要求登录，在 App 内的淘宝网页手动完成，再点「选商品图」或长按商品图。预览确认后，继续在本机识别类别和颜色。

0.6.6 在淘宝导入入口和应用内商品页提供「用图片地址」。如果网页拒绝访问，可通过手机浏览器取图。先粘贴完整分享文案，可把其中的商品名带入衣物编辑页。

应用使用黑白界面及自定义底部面板。衣物照片和色块按原色显示。拍照、文件访问和键盘由 Android 提供。

0.5.0 使用 Java 原生视图复刻用户提供的智能衣橱移动版设计。底部为「衣橱 / 洗护 / 穿搭 / 日历」四项，洗护中切换「待洗分组 / 换季检查」。待洗衣物按已确认的洗涤方式分组，可记录整组实际洗涤。穿搭画布的单品面板支持按衣橱颜色点选或拖动选色。应用继续使用原有 SQLite、图片目录和离线识别流程。

0.6.0 自动扫描提供 11 类洗标候选。换季检查将未填季节的衣物计入每一季。画布内的圆盘色盘显示已有单品及其主色，并标出选色与基准色的配色关系。

0.6.2 从单件衣物的分割区域自动提取颜色。颜色编辑加入照片取色和色相、饱和度、明度调节。颜色筛选和色盘用色块与颜色名称显示。

## 安装和构建

- 调试 APK 支持 arm64-v8a 和 x86_64，最低 Android 9（API 28）。
- Android Studio 打开此目录后同步 Gradle。构建环境为 JDK 17 或以上、Android SDK Platform 36 和 Gradle 9.4.1。Windows 可运行 `gradlew.bat :app:assembleDebug`，APK 在 `app/build/outputs/apk/debug/`。
- Windows 上如果 Android Gradle Plugin 拒绝含中文的目录，请将仓库克隆到仅含 ASCII 字符的路径。首次构建需要下载 Gradle 和 Maven 依赖。
- 公开源码可以直接构建，手动建档、洗护记录、穿搭、日历和 ML Kit OCR 无需本地 ONNX 权重。自动服装分割与分类、洗标图形检测需要分别将具有适用授权且与应用兼容的 `garment.onnx`、`care-yolo11m.onnx` 放到 `app/src/main/assets/`，再重新构建。本仓库不分发这两份权重。

## 操作路线

1. 「衣橱 → 添加」支持拍摄、相册、网购截图和手动建档。相册照片会尝试识别类别、去背景并提取颜色。截图先读取文字，可再框选商品。只需填写名称及类别即可保存。识别结果、主辅色和颜色占比均可编辑。
2. 「衣物档案 → 扫描洗标」打开紧凑的横向实时预览，画面按比例铺满。将洗标放进取景框，识别框和文字随画面持续更新。轻点预览可对焦，有变焦能力时可在预览下切换 1× 和最多 2×。稳定候选出现后可点「核对结果」，修正、移除、补录或框选重试。OCR 读取确认的画面区域，也可以直接从相册导入。最后点击「采用」和「保存」。
3. 「洗护」可记录洗涤、查看历史并完成护理检查。洗涤次数和闲置天数阈值在各衣物档案设置。护理提醒在应用内显示。
4. 「洗护 → 换季检查」选择季节即可查看当季衣物的就绪情况。未标季节的衣物参与每一季的检查。衣物可同时出现在「待洗」和「尚未重新启用」，汇总中的「洁净未启用」只计洁净的存放衣物。重新启用时可选择确认可用或标为待洗。
5. 「衣物档案 → 找颜色搭配」可按色块和类别找单品。色盘显示衣橱全部已记录颜色，同色系、邻近色、互补色和中性色规则会匹配衣橱中的颜色。编辑衣物时点击颜色或「添加颜色」，可从原图或处理图点按、拖动取色，再用滑杆调整所选颜色。
6. 「穿搭」画布可拖动、缩放、替换、移除和调整图层。「添加单品」和「替换」可用圆盘色盘按颜色找衣物。面板显示画布已有单品与主色，选中颜色后显示匹配数量和配色关系。也可以切换至「全部单品」选择未填颜色的衣物。点击「记到日历」并确认实际穿着日期，才会更新关联衣物的使用次数与最近穿着时间。
