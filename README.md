# Smart Wardrobe 智能衣橱

Smart Wardrobe 是一款帮助用户整理衣物、尝试搭配、记录穿着和管理洗护的安卓应用。

## 功能介绍

### 1. 把真实衣物收进手机

支持拍照、相册、批量照片、网购截图和淘宝链接导入，也可以手动建档。系统尝试识别衣物类别、提取颜色，以及读取商品文字，减少手动填写。

### 2. 整理衣物照片和资料

可以去除照片背景、手动框选衣物，用笔刷补回漏掉的袖口或衣摆，并调整封面。每件衣物可以记录名称、品牌、材质、颜色、季节和洗护要求。

### 3. 查找和管理衣橱

按类别、颜色、季节等条件筛选衣物，收藏常用单品；支持批量标为待洗、归档和删除。暂时不穿的衣物可以标记为“已收起”。

### 4. 体感搭配：动一动手机换衣服

左右倾斜手机切换衣物，前后倾斜切换当前操作的衣物栏，摇一摇随机组合。可以选择“上装＋下装”或“外套＋上装＋下装”，锁定喜欢的单品，只更换其他部分；还支持按季节、颜色筛选，以及触屏操作，满意后保存为穿搭。

### 5. 在画布上自由搭配

把衣物图片放到同一画布中，拖动、缩放、调整前后层次或替换单品，直观看整套组合。可以为穿搭命名、添加工作或休闲等场景，并保留草稿继续编辑。

### 6. 根据颜色寻找搭配

从一件衣物出发，查看衣橱中适合同色系、邻近色、互补色或中性色组合的单品，再加入搭配画布。

### 7. 扫描并理解洗护标签

拍摄或导入洗标照片，识别洗涤、漂白、干燥、熨烫和专业护理符号。用户可以核对、修改结果，并把要求保存到衣物档案中。

### 8. 处理待洗衣物和护理提醒

待洗衣物按具体洗涤要求分组，方便判断哪些可以一起处理。支持单件或整组登记“已洗”、撤销误操作和补记历史洗涤；也会根据洗涤次数、闲置时间提醒检查衣物。

### 9. 整理换季衣物

结合当地气温或月份提示适用季节，把收起的衣物区分为“可直接穿”和“需洗护后再穿”，支持批量取出、送洗和完成换季检查。

### 10. 用日历记录实际穿着

可以直接选择当天穿过的单品，也可以登记已保存的整套穿搭，补记过去的穿着，并查看每件衣物的穿着次数和最近穿着日期。

## 使用引导与数据保存

应用提供首次使用引导，帮助用户了解添加衣物、单品档案、洗护、换季、穿搭和日历的使用方式。衣物资料和照片主要保存在手机本地。
