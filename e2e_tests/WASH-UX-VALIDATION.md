# 洗涤交互专项验证

日期：2026-11-19。Android 0.6.15 本地重构版本，专用模拟器 emulator-5572。

构建：`gradlew.bat assembleDebug --offline --console=plain -Pandroid.overridePathCheck=true` 通过。

运行：安装 debug APK 后执行 `python -u e2e_tests/wash_ux.py`。

通过真实 UI 操作并逐步读取 SQLite 核对：

- 待洗列表「已洗」立即新增今日记录并标洁净，撤销恢复待洗与原记录数。
- 整组直接已洗及撤销，包含已收起衣物；存放状态不变。
- 待洗详情顶部直接已洗及撤销。
- 更多操作「补记洗涤」直接打开日历，今天和未来禁用，说明文字完整可见。
- 默认补记昨天，只增加历史和次数，保留待洗／洁净状态。
- 点击关闭取消补记，不新增记录。
- SQLite 完整性、外键约束及应用无崩溃检查通过。

证据目录：`results/wash-ux-1795087135317537600/`，含日期选择器截图、界面 XML、逐步数据库快照及日志。模拟器原数据单独备份并在测试后恢复；实体手机未测试。
