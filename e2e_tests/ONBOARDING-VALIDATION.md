# 聚光灯引导验证

验证日期：2026-11-21。原生 Android View，专用 API 33 模拟器，最终调试构建通过。

## 已验证

- 全新应用数据下首屏自动出现六步引导，衣橱、洗涤、护理、穿搭和日历记录均保持为空，不写入示例单品。
- 挖孔内的原始添加按钮、遮罩空白处均不能触发底层操作；跳过、上一步、下一步及完成可用，首步隐藏上一步。
- 系统返回可回到上一步；首步返回不会误退出引导。
- 跳过与完成写入 `onboarding.xml` 中的 `has_completed_onboarding=true`；冷启动不重复弹出。
- 空衣橱仍可通过筛选面板底部的「使用指南」重播；六步自动联动衣橱、洗护、穿搭和日历，未出现定位权限弹窗。
- 已有衣物使用真实首卡锚点；目标外的触摸、键盘焦点和无障碍树与底层页面隔离。卡片宽度及布局按实际视口计算，横屏时可放在目标侧边。
- 1.3 倍系统字号下步骤恢复，文案保持完整，「下一步」单行且可用。
- 关闭系统动画后仍可走完六步，无等待动画造成的死锁。
- 日历先选未来月份，再从筛选面板重播，引导结束后日历选择恢复到今天。
- 应用退到后台后实际结束进程，确认旧 PID 消失、新 PID 不同；重新打开仍恢复第 4 步，完成标记已为 true 的重播同样可以恢复。
- 涉及测试数据的操作后逐表检查数据库、核对照片文件，并恢复原数据与系统显示设置。

## 视觉实现

遮罩采用 `#111111`、约 72% 透明度，离屏图层使用 `PorterDuff.Mode.CLEAR` 挖孔，外扩 6dp；细白轮廓为 1px、约 30% 透明度。说明卡为纯白、1px 黑边、4dp 圆角。目标框移动与形变配置 240ms EaseOutCubic，说明卡交叉淡化配置 180ms，遵循系统动画设置。系统状态栏与导航栏同步压暗，退出时恢复原色。

普通字号正文最多两行；用户放大系统字体时允许增加行数以避免截断。日历网格不足以容纳说明卡时，改为高亮当天记录行；当天为空时优先高亮登记入口。所有引导文案不使用圆点分隔符或 Emoji。

## 执行与证据

`onboarding_ux.py` 覆盖空衣橱、重播、持久化、已有衣物、横屏、大字体及状态恢复。`onboarding_edges.py` 补充实际进程死亡、关闭动画与日历回到今天。脚本均限制在模拟器运行，截图、XML 和备份位于被 Git 忽略的 `results/onboarding-*/` 和 `results/onboarding-edges-*/`。

实际 TalkBack 朗读、外接键盘和实体手机尚未实测。动效时长为代码配置值，未进行逐帧计时测量。
